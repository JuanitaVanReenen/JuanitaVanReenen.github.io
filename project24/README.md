# Capital Decision Analyzer

**Investment Decision Calculator**

Capital Decision Analyzer is a browser-based decision-support tool for evaluating investment assumptions through financial metrics, scenario analysis, sensitivity analysis, break-even context, project comparison, and a printable report.

## V1 capabilities
- NPV
- IRR
- MIRR
- ROI
- Payback period
- Discounted payback
- Profitability Index
- Annual cash-flow table
- Optimistic / Base / Conservative / Stress scenarios
- Sensitivity view
- Compare up to three investments
- Print / Save as PDF report
- Browser-side calculations; no account required

## Positioning
The product is designed as decision-support software. It presents calculated consequences of user-entered assumptions and does not provide personalized investment advice or guarantee outcomes.
