# Orveli

**Internal project:** 33  
**Public product name:** Orveli  
**Type:** Software / MVP  
**Concept:** Interactive Experience Replay Software

## Core concept
Orveli turns a completed digital experience into an interactive replay that another person can follow, take control of at a selected point, and explore as an alternative branch.

## Public demo
https://juanitavanreenen.github.io/orveli/

## MVP boundary
The public prototype demonstrates the interaction model and branching replay. It does not claim production authentication, backend capture, analytics, media storage, enterprise integrations, or production deployment infrastructure.

## Buyer positioning
Orveli is intended to be presented as a technology/software asset that a software company could further develop or integrate into an existing product.

Future Orveli builds, source updates, demo recordings, visual assets, buyer documents, tests and outreach records should be preserved with the project files.
