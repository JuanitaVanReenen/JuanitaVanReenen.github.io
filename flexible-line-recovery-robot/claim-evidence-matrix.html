A working engineering matrix separating the technical elements being investigated from the evidence that currently exists. This is not a patent claim chart and does not establish novelty or patentability.

Important: broad cable untangling, cable manipulation, straightening and recovery are established technical areas. The investigation therefore focuses on the combination of the proposed elements and on measurable technical behavior. Formal patent counsel must determine whether any claim is legally supportable.

What this matrix changes

It prevents the project from relying on generic statements such as “AI untangles cables.” Instead, each proposed technical element has a defined implementation, evidence gap and legal-review question.

Architecture → simulation → bench prototype → measured trials → repeatability dataset → engineering review → patent/claim review.
