Minimum prototype acceptance sequence

  1. Single straight line acquisition.
  2. Single crossing recognition.
  3. Controlled slack creation.
  4. Crossing separation.
  5. Verification and state commit.
  6. Injected failed action.
  7. Rollback to verified state.
  8. Alternate action and successful recovery.
  9. Transfer to organization output.
  10. Repeat across defined cable/rope/strap fixtures.
Evidence boundary: The current project contains architecture, browser simulation and test definitions. It does not yet contain physical prototype measurements. No performance threshold should be represented as achieved until measured.
