Implementation blueprint

Control Package

A manufacturer-facing control blueprint for the proposed recovery machine. It defines the supervisory state machine, local module interface, sensor contract, manipulation primitives and fault handling without pretending that untested values are production limits.

Supervisory state machine

BOOT→SAFE→OBSERVE→MAP→SELECT_ACTION→EXECUTE→VERIFY→COMMIT / ROLLBACK

Every state transition should be logged with timestamp, sensor confidence, action ID, module ownership and verification result.

Sensor contract

  • RGB/depth frame + timestamp
  • Endpoint/crossing candidates
  • Module position and encoder state
  • Grip/contact state
  • Tension/force estimate

  • Loop candidates

  • Module ownership

Verification gates

  • Grip/contact consistency
  • Tension within configured envelope
  • No new unsafe crossing
  • Confidence threshold met

Failure handling

SENSOR FAULT

Preserve state

Freeze or move to a predefined safe state. Do not commit an uncertain line-state transition.

ACTION FAILURE

Rollback

Return to the last verified state when physically safe, then select an alternate action.

TENSION LIMIT

Release / retreat

Stop the current manipulation and reduce stored load according to the physical safety design.

WATCHDOG

Safe stop

Remove motion authority and require an explicit recovery sequence before re-enabling movement.
