# Water Infrastructure Decision Assurance Engine

Enterprise software IP for evidence-based assurance of major water-infrastructure decisions.

The system creates a traceable chain from requirements and source evidence through verification, conflicts, dependencies, risks and gate reviews to a human decision.

It sits above specialist engineering and infrastructure systems rather than replacing them.

## Core questions answered
What is required? What evidence supports it? Which version was used? What is verified? What conflicts or gaps exist? What downstream dependencies and risks are affected? What changed? Which gate is affected? What was presented to the decision maker? Who reviewed it under which ruleset and authorization? What was decided and on what evidence?

## Current build
Core software foundations, controlled fixtures, regression tests, governance specifications and browser demonstrations are preserved in this project directory.
