# Sulia

Sulia is a standalone messaging MVP focused on more personal communication.

## Core experience
- One-to-one and group chat concepts
- Text messaging
- Voice-message entry point
- First-class Face Messages
- Face Replies
- Face Reactions
- Profile / notifications / contacts navigation concepts

## Acquisition Demo Walkthrough — 21 September 2026

The next buyer-facing demo is planned as a short, product-led walkthrough rather than a generic promotional video:
1. Open Sulia and show the clean chat home.
2. Open a conversation and send a normal text message.
3. Switch to Face Message to show the product's defining communication mode.
4. Show the Face Message viewer and the option to respond.
5. Demonstrate Face Reply and Face Reaction.
6. Briefly show Contacts, Notifications and Profile to establish that Sulia is a complete messaging experience, not a single-feature mockup.
7. End on the Sulia value proposition: **Text when words are enough. Voice when you want to be heard. Face when you want to be there.**
