# Sulia

Sulia is a standalone messaging MVP focused on more personal communication.

## Core experience
- One-to-one and group chat concepts
- Text messaging
- Voice-message entry point
- First-class Face Messages
- Face Replies
- Face Reactions
- Profile / notifications / contacts navigation concepts

## Public demo
https://juanitavanreenen.github.io/project32/

## Demo video
The product page includes a dedicated demo-video area. The final recorded walkthrough should be captured from the working MVP so a buyer can watch the actual product flow without requesting a separate demo.

## Scope
This is a front-end demonstration MVP. It does not claim production authentication, backend persistence, media storage, moderation, calling infrastructure, or app-store packaging.
