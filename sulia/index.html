Communication Core

Sulia now includes a documented reference backend with identity, authenticated access control, message lifecycle, event history and durable JSON persistence.

Media & Realtime Foundation

The backend now includes a controlled media-upload foundation, media references for Voice and Face messages, per-user notifications and server-sent realtime conversation events.

Transferable Architecture

The browser experience is paired with a separate backend layer so a development team can continue toward production without treating the demo as the finished service.

Clear Production Boundary

Production encryption, hardened account security, object storage/CDN, push infrastructure, moderation, scaling, observability and app-store deployment remain explicit next-stage work.
