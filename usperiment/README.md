# Usperiment

**Explore what you could build together.**

Usperiment is a standalone consumer-facing dating/relationship MVP built around realistic relationship scenarios rather than generic compatibility scores.

## Core mechanism
Users explore concrete relationship scenarios, choose a position, and indicate how strongly they feel about it:
- Firm
- Important
- Flexible
- Unsure

The intended product flow is:
**Position → Stance → Discover → Compare → Explore → Decide**

## MVP boundary
This repository contains a front-end demonstration. It does not represent production authentication, identity verification, backend persistence, real messaging, media storage, moderation infrastructure, payments, or a production matching algorithm.

Demonstration profiles and scenarios are fictional.
