Product boundary

What this MVP is — and isn't.

Included in this working software

  • Relationship-position scenarios
  • Firm / Important / Flexible / Unsure stances
  • Scenario comparison and difference types
  • Conversation prompts
  • Mutual decision flow
  • Mobile-first responsive interface

Not represented as production functionality

  • Real user accounts or identity verification
  • Production matching or recommendation algorithms
  • Real messaging, media storage or social graph
  • Moderation infrastructure or payments
  • Claims that the system predicts relationship success

18+ software product working software. Demonstration profiles and scenarios are fictional. No real personal data is required for this demonstration.
