# Pulza\n\nPulza is a mobile-first social-media MVP. It keeps familiar social networking—profiles, feed, posts, reactions, comments, discovery and notifications—while introducing the Pulza: a post people can participate in through choices, joining and evolving participation.\n\n## MVP\n- Home feed\n- Discover\n- Create Post / Create Pulza\n- Reactions and comments UI\n- Pulza participation/voting\n- Notifications\n- Profile\n- Responsive mobile-first/PWA shell\n\n## Scope\nFront-end demonstration only. Production authentication, backend persistence, moderation, real media uploads, messaging and app-store packaging are future development work.\n\n## Naming\nPulza is the public product name. Project numbering is internal only.
