# PulzaFlow

PulzaFlow is a mobile-first social-media MVP. It keeps familiar social networking—profiles, feed, posts, reactions, comments, discovery and notifications—while introducing the Pulza: a post people can participate in through choices, joining and evolving participation.

## MVP
- Home feed
- Discover
- Create Post / Create Pulza
- Reactions and comments UI
- Pulza participation/voting
- Notifications
- Profile
- Responsive mobile-first/PWA shell

## Scope
Front-end demonstration only. Production authentication, backend persistence, moderation, real media uploads, messaging and app-store packaging are future development work.

## Naming
PulzaFlow is the public product name.
